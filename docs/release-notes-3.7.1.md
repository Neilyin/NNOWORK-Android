> 貼進 Play Console「版本資訊」，每個語言上限 500 字元，純文字。

## zh-TW

```
V3.7.1 帶了很多更新，體驗與 iOS 版本相同！

・換工作也能留下回憶：開新卡，舊卡收進「過往工作」，隨時回顧
・集滿第 3 張成為「忍耐大師」，先看階段性總結
・離職結算改成 RPG 破關風格
・國定假日一鍵匯入：依手機地區自動判斷，支援 9 個地區的 2027 年假日
・薪水計時器桌面小工具
・摺疊機、平板支援左右雙欄
・樹洞留言不再限制字數
・全新介面：柔和框線、卡片陰影、深色主題文字更清楚
・新增使用說明書與 App 內更新提示
```
